# inbox/ — 素材置き場

この事例に関する素材（ヒアリングメモ・アンケート回答・数値データ・議事メモ等）を
随時ここに追加する。形式は自由（.md / .txt / .csv など）。

- ファイル名は `YYYYMMDD-<内容>.md` 形式（例: `20260401-hearing-memo.md`）
- 素材が溜まったら Claude に「正本化して」と依頼 → `case.md` に構造化される
- 正本化済みの素材も削除せず残す（出典として辿れるように）

> **注意**: このリポジトリは public。ここに置いた瞬間から公開される。
> 掲載許諾前の実名・商談情報・未公開価格は**匿名化してから**置くこと。
> 画像は inbox/ ではなく `../assets/` へ。
