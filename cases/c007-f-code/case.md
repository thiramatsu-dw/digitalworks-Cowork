## 課題（Before）

- レポート作成のため様々なシステムから大量のデータを手動で収集・集計しており、時間が掛かるうえミスも多発
- API 非対応媒体のレポーティングや画面キャプチャ取得は手作業のまま
- エンジニアに自動化を依頼しても、開発リソースの優先度調整が難しく進まなかった

## 導入の決め手

- 無料トライアルで使い勝手の良さを実感し、早々に導入を決断
- ファイル操作・BI ツール操作などブラウザ外の作業が多く、SaaS 型 RPA では実現できなかったため**デスクトップ型**の RaQubo を選択
- エンジニアに頼らず**自分自身でどんどん自動化を構築できる**こと

## 施策・使い方

- 広告レポートのロウデータ取得の自動化、広告掲載面チェックの画面キャプチャリング
- 月次レポートは出社前に RPA が仕掛かりを作成し、最終まとめ・体裁のみ人が実施
- 行き詰まったら短いシナリオでピンポイント動作検証、画像認識が難しい画面はメール経由で情報取得に切り替えるなど柔軟に回避

## 成果（After）

- ロウデータ取得の自動化で**毎日約 3 時間を削減**
- レポート作成のリードタイム短縮、作業漏れなど**ミスの削減**、作業ストレスも大幅軽減
