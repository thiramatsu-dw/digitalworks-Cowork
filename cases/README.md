# 導入事例（cases/）

プロダクトの導入事例を「事例毎のプロジェクトフォルダ」で管理し、
素材の蓄積 → 正本化 → 媒体別アウトプット（Web・セールス資料・LP パーツ）に
展開するためのディレクトリ。

**事例に関する作業は必ず `case-content` スキル
（`.claude/skills/case-content/SKILL.md`）に従うこと。**

## 構造

```
cases/
├── README.md                   # このファイル（事例一覧の正本。事例追加時に必ず更新）
├── index.html                  # 事例カタログ（ブラウザ / GitHub Pages で見る一覧）
├── _template/                  # 新規事例フォルダの雛形
└── cNNN-<slug>/                # 事例プロジェクトフォルダ（連番 + 英小文字ケバブ）
    ├── case.md                 # 事例の正本（メタ情報 + 構造化された事例内容）
    ├── inbox/                  # 随時アップする素材（メモ・ヒアリング・データ）
    ├── assets/                 # 画像（ロゴ・利用シーン写真・グラフ等）
    └── outputs/                # 媒体別アウトプット（正本から生成）
        ├── web/index.html      # Web サイト用の事例詳細ページ
        ├── lp-embed/           # LP の事例セクションに貼る HTML 断片
        └── slides/             # セールス資料用スライド（.pptx / .pdf）
```

## ステータス定義

| ステータス | 意味 |
|---|---|
| 素材収集中 | inbox/ に素材を蓄積している段階。case.md は未完成 |
| 正本化済 | inbox/ の素材を case.md に構造化・書き起こし済み |
| 公開可 | 掲載許諾・レビューが完了し、アウトプット生成が可能 |
| 掲載中 | Web・セールス資料等に掲載されている |

## 掲載許諾ステータス

| 許諾 | 扱い |
|---|---|
| 未申請 / 申請中 | 顧客名・特定可能情報はリポジトリに一切書かない（匿名表記のみ） |
| 実名許諾済 | 実名・ロゴ・実測数値を掲載可（許諾範囲のメモを case.md に残す） |
| 匿名のみ可 | 「業種・規模」の属性表記で掲載（例: 製造業・従業員 300 名） |

> **重要**: このリポジトリは public。`inbox/` に置いた瞬間から公開される。
> 未許諾の実名素材・商談情報は匿名化してからコミットすること。
