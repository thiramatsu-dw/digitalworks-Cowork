# デザインパターンカタログ

LP のデザインパターン（構成・レイアウト・トーンの型）を再利用可能なアセットとして
蓄積するディレクトリ。新しい LP を作るときは、まずここから訴求・ターゲットに合う
パターンを選ぶ。

## 使い方

1. 下のカタログ表からパターンを選ぶ
2. `pNNN-<slug>/PATTERN.md` を読み、参照実装の HTML をコピーして出発点にする
3. デザイントークン（CSS 変数）とコピーをプロダクトに合わせて差し替える

詳細な手順は `.claude/skills/lp-create/SKILL.md`（ワークフロー A）を参照。

## パターン登録のルール

- 良いデザインの LP ができたら `pNNN-<slug>/PATTERN.md` として登録する（連番）
- PATTERN.md は `p001-saas-zigzag/PATTERN.md` と同じ見出し構成で書く
- 参照実装は `lp/` 配下の実 LP を指す（パターン側に HTML を複製しない）
- 登録したら下のカタログ表に 1 行追加する
