# p001: saas-zigzag — 王道 SaaS 型・ジグザグ機能紹介

## 概要

明るい紙色ベースに、濃色の「数字バンド」「ダークショーケース」「CTA」を挟んで
緩急を作る、BtoB SaaS の王道構成。機能紹介は左右交互（ジグザグ）のスクリーン
ショット + ベネフィット箇条書きで、読み疲れさせずに 5 機能程度を見せられる。

- **参照実装**: [`lp/workmonitor/lp002/index.html`](../../lp/workmonitor/lp002/index.html)
- **登録日**: 2026-08-16

## 適する訴求・ターゲット

- プロダクトの実画面（スクリーンショット）が豊富にある SaaS・ツール
- 経営者・意思決定者向けに「平易な言葉 + 具体的な数字」で語る訴求
- 「不安の打ち消し」（セキュリティ・プライバシー等）を丁寧に扱いたい商材

向かない場合: 画面を見せられない無形サービス（→ 図解中心のパターンを選ぶ）、
ストーリー没入型で読ませたい訴求（→ 縦読みストーリー型を選ぶ）。

## デザイントークン

`:root` で定義。プロダクトに合わせてここだけ差し替える。

```css
:root {
  --navy: #14306e;        /* プライマリ */
  --navy-deep: #0b1d45;   /* プライマリ濃（数字バンド・ダーク背景） */
  --navy-ink: #101b3d;    /* 見出し文字 */
  --navy-tint: #eef3fc;   /* プライマリ淡（背景パネル） */
  --amber: #f59e0b;       /* アクセント 1（CTA グラデ始点） */
  --orange: #f97316;      /* アクセント 2（CTA グラデ終点） */
  --amber-soft: #fff7e8;  /* アクセント淡 */
  --ink-sub: #5a6478;     /* 補助文字 */
  --line: #e4e9f2;        /* 罫線 */
  --paper: #f7f9fd;       /* 紙色（淡背景） */
}
```

特徴的な意匠:

- hero 背景: 2 つの radial-gradient + 薄いグリッド線（mask で下にフェード）
- CTA ボタン: アクセント 2 色の `linear-gradient(135deg)` + 色付きシャドウ
- スクショは必ず「ブラウザ風フレーム」（ドット 3 つ + アドレスバー）に入れる
- 機能行の背景に、ずらした角丸パネル（`.feat-media::before`）を敷く

## レスポンシブ方針

- ブレークポイント: **860px**（2 カラム → 1 カラム、ジグザグ解除）、
  **560px**（ボタン全幅化・カード縮小）、ほか微調整 720/760/880px
- 数字バンドは 4 列 → 2 列。導入フローは横 4 ステップ → 縦タイムライン
- 見出し・余白はすべて `clamp()` で流動化
