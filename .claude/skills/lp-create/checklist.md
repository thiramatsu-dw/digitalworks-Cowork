# LP 公開前チェックリスト

完了報告の前に全項目を確認する。ブラウザでの実表示確認（不可能な環境では
HTML の静的検証 + 構造確認）を必ず行う。

## 構造・技術

- [ ] 自己完結の静的 HTML 1 ファイル（外部 CDN・外部フォント・ビルド依存なし）
- [ ] 画像パスは `../assets/...` 相対参照で、全画像が実在する
- [ ] `lang="ja"` / `<title>` / `<meta name="description">` / viewport 設定済み
- [ ] 色がすべて `:root` のデザイントークン経由になっている
- [ ] 560px / 860px / PC の 3 段で崩れ・横スクロールが無い
- [ ] 全画像に具体的な `alt` と `width`/`height` がある
- [ ] `prefers-reduced-motion` でアニメーションが止まる
- [ ] アンカーリンク（ナビ → セクション id）がすべて機能する

## コピー・事実性

- [ ] 文言はプロダクト README（訴求正本）と矛盾しない
- [ ] 数値・機能名に根拠がある（未確定の実績・架空の声が無い）
- [ ] 料金表記がプロダクトの決定ルールに従っている
- [ ] 誇大表現・NG ワードが無い（tone-and-manner.md 参照）
- [ ] 内部戦略・内部数値が書かれていない
- [ ] 提供会社表記・フッター・コピーライトが共通表記どおり

## CTA

- [ ] ヘッダー・hero・末尾の 3 箇所以上に CTA がある
- [ ] CTA のリンク先が正しい（プロダクト README の CTA 方針どおり）
- [ ] CTA 文言が行動を表す動詞になっている

## 運用

- [ ] 命名規則どおりのパス（`lp/<product>/lp00N[-x]/index.html`）
- [ ] `lp/index.html`（カタログ）に追加済み
- [ ] 新パターンの場合: `patterns/` に PATTERN.md を登録し README のカタログ表を更新済み
